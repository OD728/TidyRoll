# Tidy Roll changelog

## 1.0.1

- Renamed to **Tidy Roll**, folder included. Delete the old `TidyRolls` folder from your AddOns if it is still there. Your saved bar position does not carry over: drag the bars back with `/tidyrolls unlock` if you had moved them.

## 1.0.0

First release.

- Slim loot roll bars replacing the game's roll frames: item icon, Need / Greed / Pass, timer bar.
- Counts on the buttons and a tooltip listing who picked what, with roll numbers.
- Winner shown when the roll ends.
- Movable with `/tidyrolls unlock`; sample bars with `/tidyrolls`.
