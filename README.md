# Tidy Roll

![Tidy Roll](art/curseforge-logo.png)

**Clean, compact loot roll bars**, made for WoW: Forever.

- Slim bars replace the game's roll frames: item icon, Need / Greed / Pass, and a timer bar.
- Counts on the buttons, and a tooltip listing who picked what, with roll numbers.
- The winner is shown when the roll ends.

## Install

Download it from CurseForge, or copy this repository's files into a folder named
`TidyRoll` inside `World of Warcraft\_forever_\Interface\AddOns\`.

## Commands

| Command | What it does |
| --- | --- |
| `/tidyrolls` | Show or hide sample bars |
| `/tidyrolls unlock` | Drag the bars where you want them |
| `/tidyrolls lock` | Fix them in place again |
| `/tidyrolls reset` | Put them back in the default spot |

## Options

Size, width, stacking direction, how long finished bars stay, the Disenchant
button, fonts and colors are all set at the top of `TidyRoll.lua`.
